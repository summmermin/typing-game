# 산성비 - 타자 게임 (ACID RAIN)

추억의 "한컴 타자연습" 산성비 모드에서 영감을 받아 제작된 터미널 스타일의 타자 연습 게임입니다.

화면 위에서 단어들이 떨어집니다 — 바닥에 닿기 전에 타이핑하여 단어를 파괴하세요!

## 게임 방법

1. 아무 브라우저에서나 `typing-game.html` 파일을 엽니다.
2. 난이도를 선택합니다:
   - **Lv.0** — 느린 속도, 적은 단어
   - **Lv.1** — 보통 속도
   - **Lv.2** — 엄청나게 빠른 속도
3. 떨어지는 단어를 입력한 후 **Enter** 또는 **Space(스페이스바)**를 누르면 단어가 사라집니다.
4. 입력 중인 단어와 일치하는 글자는 초록색으로 하이라이트됩니다.

## 게임 규칙

- **3개의 단어**를 놓치면 = 게임 오버 (Game Over)
- **30개의 단어**를 제거하면 = 승리! (Victory)
- 레벨이 올라갈수록 단어가 떨어지는 속도가 빨라집니다.
- 연속으로 단어를 맞추면 콤보 보너스를 획득합니다.

## 주요 기능

- 한국어(70%)와 영어(30%)로 구성된 단어 풀(Pool)
- 실시간 콤보 카운터 및 레벨업 시스템
- 레벨별 속도 배율 증가
- 클리어 진행 상황을 보여주는 프로그레스 바(진행률 표시줄)
- 게임 결과(승리/패배)에 따른 랜덤 메시지 출력
