# ACID RAIN - Typing Game

Terminal typing practice game inspired by the classic Korean "Hancom Typing Practice" acid rain mode.

Words fall from the top of the screen — type them before they hit the bottom!

## How to Play

1. Open `typing-game.html` in any browser
2. Select difficulty:
   - **Lv.0** — Slow pace, few words
   - **Lv.1** — Medium speed
   - **Lv.2** — Insane speed
3. Type the falling word and press **Enter** or **Space** to destroy it
4. Matching words highlight in green as you type

## Rules

- Miss **3 words** = Game Over
- Clear **30 words** = Victory!
- Speed increases as you level up
- Combo bonuses for consecutive correct inputs

## Features

- Korean (70%) + English (30%) word pool
- Real-time combo counter and level-up system
- Speed multiplier increases per level
- Progress bar showing clear status
- Random result messages (win/lose)

## Quick Start

```bash
open typing-game.html
```
